# ai_employee docs/templates folder is never built

## Request
Zensical never builds ai_employee's docs/templates/ folder. That's the file you have open, templates/ai_employee/docs/templates/follow-up.md, so it has never appeared on a built site. The fix is renaming the folder (for example to forms/) and updating the ~9 links to it.

## Analysis
Zensical leaves a docs folder named `templates/` out of the build. A project made from the
ai_employee template therefore has no Templates pages (index, call notes, follow-up email) in
`site/`, and the build gives 9 "page does not exist" warnings for the links to them. The committed
version has the same problem (10 warnings back then), so it's an old bug that predates the plugin
work. It's a `bug` because existing content silently goes missing.

**Confirmed by experiment:** in a scratch copy of a new ai_employee project, renaming
`docs/templates/` to `docs/forms/` and rewriting the links gives `site/forms/{index.html,
call-notes/, follow-up/}` and **0 warnings** (it was 9). So the folder name alone is the cause. The
docs root also holds `docs/overrides/` (`custom_dir`); a `templates` name is probably reserved for
theme templates.

The 9 links, in 6 files, all of the form `templates/<page>.md` or `../templates/<page>.md`:
- `docs/index.md:28-30` (3: Templates, Call notes, Follow-up email)
- `docs/memory.md:43` ("add to [Templates](templates/index.md)")
- `docs/library/production.md:14`, `docs/library/sales.md:14,24`
- `docs/people/clients.md:30`, `docs/transcripts/index.md:20`

Also:
- `zensical.toml`: the llmstxt "Templates" section was left out because the folder isn't built
  (decision `2026-11-01.ai-employee-s-llmstxt-sections-leave.md`). Add it back with the new path.
- `docs/zensical/compatibility.md` mentions that the ai_employee template has a `templates/` folder; update that line.
- Gotcha in `decisions/gotchas.md` (templates/ folder not built) stays as general knowledge.
- macOS `sed` has no `\|` alternation; rewrite the links with Python or `sed -E`.

Open question:
- New folder name: `forms/` (as suggested), or e.g. `formats/`, `boilerplates/`, `snippets/`. The
  page title "Templates" can stay as the link text and the H1, since only the folder name matters.
