# CI workflows never run on main

## Request
Both CI workflows (`.github/workflows/bash_unit.yml`, `shellcheck.yml`) trigger only on `master`, but the branch is `main`, so the new tests and shellcheck never run in CI.

## Analysis
Both workflows have `on: push/pull_request: branches: [ master ]`. The repo's only default branch
is `main` (`git branch -a`: local `main` and `origin/main`, no `master`). CI is meant to run but
silently never does, so this is a bug. The fix itself is `master` → `main` in 4 lines.

Once the workflows do run, they will probably fail right away. The trigger is only half the fix:
- **shellcheck.yml** runs `ls ./*.sh | xargs shellcheck` at the default severity. `mkdox2.sh` has
  2 old SC2001 style notes (lines ~639/641, `echo | sed 's/\r$//'`), so the job goes red. Options:
  fix those 2 lines, or use `shellcheck -S warning` (which is clean).
- **bash_unit.yml** runs `tests/bash_unit tests/test_*` from the repo root. But
  `tests/test_basic.sh` finds the script with `root_folder=$(cd .. && pwd)`, which is relative to
  the current directory. From the repo root that is the parent folder, so no `*.sh` is found and
  the tests fail. `tests/run_tests.sh` runs them from `tests/` instead (`cd "$script_path"`).
  Fix: `cd tests` before running, or make the test find the script from its own location
  (`$(dirname "${BASH_SOURCE[0]}")/..`).
- Both use `actions/checkout@v2`, which GitHub has deprecated (it runs on an old Node version);
  bump to `@v4`.
- The macOS job runs only with `[macos]` in the commit message and installs only `gawk`. macOS
  ships bash 3.2, and `mkdox2.sh` needs bash 4+ (`${action,,}`). It needs `brew install bash` too,
  or it fails when it does run.
- Docker: the new `new` menu tests stop before `Docker:require_running`, but `Os:require "docker"`
  still needs the `docker` binary. `ubuntu-latest` has it; the macOS runner doesn't.

Open questions:
- Fix the 2 SC2001 lines, or run shellcheck with `-S warning`?
- Keep, fix or drop the opt-in macOS job?

## Impacted files
- `.github/workflows/bash_unit.yml`: branch `main`, `actions/checkout@v4`, run the tests from `tests/`; macOS job: also install bash, or drop the job
- `.github/workflows/shellcheck.yml`: branch `main`, `actions/checkout@v4`, severity or include the fix
- `tests/test_basic.sh`: only if the root folder is derived from the test file location
- `mkdox2.sh`: only if the 2 SC2001 notes are fixed instead of lowering the severity
