# Dead pip packages leave the Docker image in the next image update, not with the template plugins

## Context
Zensical only runs plugins on its supported list. docker/Dockerfile pip-installs mkdocs-autolinks-plugin, mkdocs-awesome-pages-plugin, mkdocs-include-markdown-plugin, mkdocs-rss-plugin and markdown-include, which are either unsupported, native or (markdown-include) not loaded.

## Options considered
- Remove them together with the template plugin change: mixes a template change with an image rebuild and push.
- Remove them in the next image update: the templates change now, the image stays as is.

## Decision
Dead pip packages leave the Docker image in the next image update, not with the template plugins

## Consequences
docker/Dockerfile keeps the dead packages for now. Removing them needs a rebuild + push of pforret/mkdox-zensical (multi-arch, via `docker/push_docker.sh`).
