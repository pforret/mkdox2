# Enter at the template prompt picks simple

## Context
Planning the template-menu item (request: "default template should be: simple site, then site + blog, then Karpathy wiki and that's it"). Before this, an empty answer at 'Pick a template' died with "Invalid choice".

## Options considered
- Enter = 1 (simple): the common case takes one keystroke; shown in the prompt as `[1-3, Enter=1]`.
- Must type a number: strict, but slower and gives an error for the most likely answer.

## Decision
Enter at the template prompt picks simple

## Consequences
The first entry of the menu array is the default, so reordering the array changes the default. Piped/empty stdin also gets `simple`.
