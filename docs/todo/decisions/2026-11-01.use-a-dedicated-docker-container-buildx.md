# Use a dedicated docker-container buildx builder (mkdox-builder) for the multi-arch push

## Context
The PRP for B1 planned `docker buildx build --platform linux/amd64,linux/arm64 --push` on the default builder. The first push failed: "Multi-platform build is not supported for the docker driver" (this Docker Desktop has no containerd image store).

## Options considered
- Default builder, as in the spec: doesn't work here.
- Turn on the containerd image store in Docker Desktop: a machine-wide setting other people running `push_docker.sh` would also have to change.
- A dedicated `docker-container` builder created by the script if missing: works without changing global settings; adds a buildkit container that stays around.

## Decision
Use a dedicated docker-container buildx builder (mkdox-builder) for the multi-arch push

## Consequences
`docker/push_docker.sh` runs `docker buildx create --name mkdox-builder --driver docker-container` on first use and builds with `--builder mkdox-builder`. Local single-arch `--load` test builds still use the default builder. Remove the builder with `docker buildx rm mkdox-builder` if needed.
