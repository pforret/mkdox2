# Show a -B usage example for hidden templates in mkdox2 help

## Context
The plan hid `ai_employee`, `committee` and `dev_project` from the `mkdox2 new` menu but kept them usable with `-B`. The PRP didn't say how users would find them.

## Options considered
- No hint: the hidden templates are only findable by reading `templates/`.
- A `#TIP:> $script_prefix -B dev_project new <name>` line, which bashew shows in the usage/help output: one line, makes `-B` discoverable.

## Decision
Show a -B usage example for hidden templates in mkdox2 help

## Consequences
`mkdox2` help shows a `-B` example. If templates are renamed or the hidden set changes, update that TIP line in the `new)` action.
