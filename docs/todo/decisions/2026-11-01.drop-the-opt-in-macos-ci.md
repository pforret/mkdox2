# Drop the opt-in macOS CI job; CI tests run on ubuntu-latest only

## Context
Fixing the CI workflows (they only triggered on `master`, the branch is `main`). `.github/workflows/bash_unit.yml` had a macOS job that ran only with `[macos]` in the commit message, and it would fail: it installed only gawk, macOS ships bash 3.2 while mkdox2.sh needs bash 4+, and the macOS runner has no docker binary for `Os:require "docker"`.

## Options considered
- Drop it: ubuntu covers the tests; macOS runner minutes cost 10x; it never ran.
- Fix it, keep opt-in: brew install bash gawk + a docker CLI; more to maintain, still rarely runs.
- Fix it, run always: best coverage, slowest and most expensive CI.

## Decision
Drop the opt-in macOS CI job; CI tests run on ubuntu-latest only

## Consequences
CI runs on ubuntu-latest only. macOS-specific behaviour (BSD sed/awk, bash from Homebrew) is only tested locally with `./tests/run_tests.sh`.
