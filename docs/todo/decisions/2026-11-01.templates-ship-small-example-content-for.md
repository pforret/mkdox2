# Templates ship small example content for their plugins

## Context
Planning "Add Zensical plugins to the templates" (request: add llmstxt, tags, glightbox, privacy, minify, social, callouts, markdown-include). tags and callouts do nothing visible without content that uses them, and `about/features/plugins.md` still listed awesome-pages and with-pdf.

## Options considered
- Small examples: `docs/tags.md` with `<!-- material/tags -->`, `tags:` on 2-3 pages, one callout, updated plugins page.
- Config only: nothing visible until users use the features.

## Decision
Templates ship small example content for their plugins

## Consequences
Each template has a tags index page and a few tagged pages; users can delete them. The tags index needs the `<!-- material/tags -->` marker, since the plugin ignores `tags_file`.
