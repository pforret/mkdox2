# All templates enable llmstxt, tags, glightbox, privacy, minify, social and callouts

## Context
Planning "Add Zensical plugins to the templates" (request: add llmstxt, tags, glightbox, privacy, minify, social, callouts, markdown-include). All seven native plugins were tested on Zensical 0.0.74 and work; the question was which templates get which.

## Options considered
- All 7 in all 6 templates: one consistent block, only llmstxt `sections` differ.
- Per-template matrix (e.g. llmstxt only for AI templates, social only for the blog): leaner sites, 6 different blocks.
- Core plugins everywhere, extras per template.

## Decision
All templates enable llmstxt, tags, glightbox, privacy, minify, social and callouts

## Consequences
Every template's zensical.toml has the same 7 plugin blocks (plus search; with_blog also blog/rss). A plugin change goes into all six files. Only `[project.plugins.llmstxt.sections]` is template-specific.
