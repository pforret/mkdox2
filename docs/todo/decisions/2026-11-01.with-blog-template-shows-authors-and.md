# with_blog template shows authors and a draft post, not the full blog plugin feature set

## Context
Checking with_blog against the Zensical blog docs showed the template used only dates, categories and excerpts. The question was how many plugin features the template should show.

## Options considered
- Authors + one draft post: shows the common features, small.
- Full showcase (categories allow-list, pagination, pinned, created/updated dates, related links): more to learn from, more for users to delete.
- Keep minimal: only fix what's wrong.

## Decision
with_blog template shows authors and a draft post, not the full blog plugin feature set

## Consequences
with_blog has `docs/blog/.authors.yml` (author `{USERNAME}`), `authors:` on its posts, and a `draft: true` example that only shows in `mkdox2 serve`. Posts that name an author missing from `.authors.yml` break the build, which is why `mkdox2 post` doesn't add `authors:`.
