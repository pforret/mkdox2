# Remove the awesome-pages plugin entry from all templates

## Context
`[project.plugins.awesome-pages]` was enabled in all 6 templates. A with_blog build with and without it gave the same navigation, and no template has `.pages` files. `docs/zensical/compatibility.md` lists awesome-pages as unsupported (Zensical's replacement is native modular navigation).

## Options considered
- Remove from all 6 templates: no dead config for users to copy.
- Only from with_blog: stays in this item's scope, but leaves 5 dead entries.
- Keep it: harmless, but misleading.

## Decision
Remove the awesome-pages plugin entry from all templates

## Consequences
New projects no longer list awesome-pages. The `mkdocs-awesome-pages-plugin` pip package is still in docker/Dockerfile; removing it belongs with a later image update.
