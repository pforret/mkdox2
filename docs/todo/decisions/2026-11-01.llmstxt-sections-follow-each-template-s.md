# llmstxt sections follow each template's top-level folders, with llms-full.txt and Copy-as-Markdown

## Context
While testing, llmstxt without `sections` (a required setting) built without error but gave a header-only `llms.txt`.

## Options considered
- Per-template sections from the top-level folders + `full_output = "llms-full.txt"` + `content.action.copy`: useful output for AI readers, plus a Copy-as-Markdown button.
- One catch-all glob for every template: the same in each file, but no meaningful sections.

## Decision
llmstxt sections follow each template's top-level folders, with llms-full.txt and Copy-as-Markdown

## Consequences
Each template's `[project.plugins.llmstxt.sections]` lists its own folders. When a template gets a new top-level folder, add it to the sections, or its pages won't be in `llms.txt`.
