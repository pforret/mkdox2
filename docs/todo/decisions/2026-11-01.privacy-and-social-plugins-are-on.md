# privacy and social plugins are on by default in the templates

## Context
Planning "Add Zensical plugins to the templates" (request: add llmstxt, tags, glightbox, privacy, minify, social, callouts, markdown-include). privacy downloads external assets (Google Fonts, CDN scripts, avatars) at build time; social renders a PNG card per page.

## Options considered
- Both on: the first build needs network and is a few seconds slower; later builds are cached (0.45 s, works with `--network none`); GDPR-friendly fonts and proper link previews.
- privacy on, social off.
- Both off, commented out for opt-in.

## Decision
privacy and social plugins are on by default in the templates

## Consequences
New projects build with network the first time and keep a `.cache/` folder (ignored by the template `.gitignore`). Social cards use `site_url`, so it must be set to the real domain before publishing.
