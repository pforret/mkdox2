# Remove helpers in mkdox2.sh that lose their last caller (find_md_raw_title)

## Context
The with_blog item's PRP said to remove `find_md_*` helpers only when no caller is left after deleting `mkdox2 blog`. `find_md_raw_title` was used only by that action.

## Options considered
- Keep unused helpers: no risk, but dead code (and it held the 2 old SC2001 shellcheck notes).
- Remove helpers with no remaining caller (`grep -c`): smaller script, shellcheck clean at the default level.

## Decision
Remove helpers in mkdox2.sh that lose their last caller (find_md_raw_title)

## Consequences
`find_md_raw_title` is gone; `find_md_date` and `find_md_short` stay because `toc` uses them. When removing an action, grep each helper it used and delete the ones without callers.
