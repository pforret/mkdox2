# shellcheck.yml installs shellcheck when it is missing, so the workflow also runs under act

## Context
The CI item planned only to change the trigger branch and the checkout version. Testing the workflow locally with `act` (image `catthehacker/ubuntu:act-latest`) failed with `xargs: shellcheck: No such file or directory`: that image lacks shellcheck, while GitHub's `ubuntu-latest` has it preinstalled.

## Options considered
- Leave the workflow as specified: works on GitHub, can't be tested locally with act.
- Add `command -v shellcheck || (sudo apt-get update -qq && sudo apt-get install -y -qq shellcheck)`: a no-op on GitHub (about 0 s), about 30 s under act; the workflow is testable locally.

## Decision
shellcheck.yml installs shellcheck when it is missing, so the workflow also runs under act

## Consequences
`act push -W .github/workflows/shellcheck.yml -P ubuntu-latest=catthehacker/ubuntu:act-latest` works locally. The bash_unit workflow still can't pass under act, because act runs as root and mkdox2.sh refuses root (see gotchas.md).
