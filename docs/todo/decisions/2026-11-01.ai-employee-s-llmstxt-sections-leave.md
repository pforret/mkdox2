# ai_employee's llmstxt sections leave out docs/templates/ until that folder is renamed

## Context
The PRP said llmstxt `sections` follow each template's top-level folders. For ai_employee that included `"Templates" = ["templates/*.md"]`, but Zensical doesn't build a docs folder named `templates/`, so the section came out as an empty heading in `llms.txt`.

## Options considered
- Keep the section (spec): an empty "Templates" heading in every ai_employee `llms.txt`.
- Leave it out: no empty section; the Templates pages are missing from `llms.txt`, as they are from the site.
- Rename the folder now: out of scope for a plugin item (it touches ~9 links).

## Decision
ai_employee's llmstxt sections leave out docs/templates/ until that folder is renamed

## Consequences
When ai_employee's `docs/templates/` is renamed (e.g. to `forms/`), add it back as an llmstxt section with the new path.

> Resolved by the item "ai_employee docs/templates folder is never built": the folder is now `docs/forms/` and the llmstxt section is back as `"Templates" = ["forms/*.md"]`.
