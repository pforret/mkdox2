# Template menu order is a hardcoded array in mkdox2.sh

## Context
Planning the template-menu item (request: "default template should be: simple site, then site + blog, then Karpathy wiki and that's it"). The menu order was alphabetical (a glob over `templates/*/`); the requested order isn't alphabetical.

## Options considered
- Hardcoded array in mkdox2.sh (`menu_templates=(simple with_blog karpathy_wiki)`): one obvious line; adding a menu template needs a script edit.
- A marker file (e.g. `menu_order`) per template folder: no code change for new templates, but more files and parsing.

## Decision
Template menu order is a hardcoded array in mkdox2.sh

## Consequences
To add or reorder a menu template, edit the array in the `new)` action of mkdox2.sh. Adding a folder to `templates/` alone doesn't put it in the menu.
