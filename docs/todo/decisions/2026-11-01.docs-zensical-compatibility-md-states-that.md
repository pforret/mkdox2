# docs/zensical/compatibility.md states that unsupported third-party plugins are not loaded at all

## Context
The PRP only asked to drop the outdated "blog/rss not yet supported" line. While editing, the Zensical docs showed that plugins not on its supported list are not imported or run at all.

## Options considered
- Only fix the blog/rss line (spec).
- Also state that unsupported plugins are not loaded and pip-installing them does nothing: explains why `docker/Dockerfile`'s plugin installs are useless.

## Decision
docs/zensical/compatibility.md states that unsupported third-party plugins are not loaded at all

## Consequences
compatibility.md now has rows for blog, rss (native) and awesome-pages (not supported), plus the "not loaded" note. Its git-* rows are still wrong (they're Planned, not native); see gotchas.md.
