# Command hints and help text in mkdox2.sh say mkdox2, not mkdox

## Context
While testing B1 (Zensical image update), the hint printed after `mkdox2 new` said "run 'mkdox serve'", and the option help said "for mkdox new/build". The user pointed out that `mkdox` is the older MkDocs-based tool and that the right command is `mkdox2`. The PRP didn't include this.

## Options considered
- Leave as is (spec scope): users get pointed at the wrong, MkDocs-based tool.
- Fix it in B1: small change, in the same file B1 already touched.

## Decision
Command hints and help text in mkdox2.sh say mkdox2, not mkdox

## Consequences
mkdox2.sh lines 187/191 use `$script_prefix serve` (resolves to `mkdox2`), and the help text says `mkdox2`. New user-facing hints should use `$script_prefix`, not a hardcoded name.
