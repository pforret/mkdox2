# docs/zensical/compatibility.md follows Zensical's plugin page as the source of truth for plugin status

## Context
The item asked to fix the git-* rows (listed as "Native built-in" but Planned). Comparing the table with https://zensical.org/docs/compatibility/mkdocs/plugins/ showed mkdocstrings, macros, minify, mike and static-i18n were also wrong, and the Features table claimed "revisioning" was supported.

## Options considered
- Fix only the 3 git-* rows (spec): the rest of the table stays wrong.
- Rewrite the table from the plugin page, with since-versions and a link to the full list: the whole page is correct as of 0.0.74.

## Decision
docs/zensical/compatibility.md follows Zensical's plugin page as the source of truth for plugin status

## Consequences
The plugin table states "status as of Zensical 0.0.74" and links to the official page. When the Docker image moves to a new Zensical version, re-check the table against that page.
