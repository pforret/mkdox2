# minify runs with minify_html, minify_inline_js and minify_inline_css

## Context
While testing, `[project.plugins.minify]` with no settings did nothing: all `minify_*` options default to false.

## Options considered
- `minify_html` only.
- `minify_html` + `minify_inline_js` + `minify_inline_css` (the inline options are Zensical-only): tested, index.html 24 KB → 18 KB, single line.

## Decision
minify runs with minify_html, minify_inline_js and minify_inline_css

## Consequences
Generated HTML is one line, so read the source in `docs/`, not in `site/`. `serve` and hot-reload still work (tested).
