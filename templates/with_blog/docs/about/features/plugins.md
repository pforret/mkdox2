# Installed plugins

* [search](https://zensical.org/docs/compatibility/mkdocs/plugins/#search): full-text search
* [llmstxt](https://zensical.org/docs/compatibility/mkdocs/plugins/#llmstxt): `llms.txt` index, `llms-full.txt` and Markdown copies of pages for AI readers, plus a "Copy as Markdown" button
* [tags](https://zensical.org/docs/compatibility/mkdocs/plugins/#tags): `tags:` in the front matter, listed on the [tags](../../tags.md) page
* [glightbox](https://zensical.org/docs/compatibility/mkdocs/plugins/#glightbox): click an image to enlarge it
* [privacy](https://zensical.org/docs/compatibility/mkdocs/plugins/#privacy): external fonts, scripts and images are downloaded and served from this site
* [minify](https://zensical.org/docs/compatibility/mkdocs/plugins/#minify): smaller HTML, inline JavaScript and CSS
* [social](https://zensical.org/docs/compatibility/mkdocs/plugins/#social): social cards and Open Graph tags for link previews (uses `site_url`)
* [callouts](https://zensical.org/docs/compatibility/mkdocs/plugins/#callouts): Obsidian-style `> [!NOTE]` callouts
* [blog](https://zensical.org/docs/setup/blog/): posts, archive, categories, authors and drafts
* [rss](https://zensical.org/docs/compatibility/mkdocs/plugins/#rss): RSS feeds of the blog posts

All of them are built into Zensical: there is nothing to install. Includes use the `pymdownx.snippets`
